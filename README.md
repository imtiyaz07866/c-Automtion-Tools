# 🌐 YouTube to Facebook Auto-Poster (24/7 Cloud Web Application)

Yeh ek **Cloud Web Application** hai jo YouTube channel se automated video fetch karke aapke Facebook Page par upload karta hai. **Aapko coding aana bilkul zaroori nahi hai.**

---

## 🌟 Yeh Web App Kaise Kaam Karta Hai?

1. **Dashboard Interface**: Ek bilkul simple web application jahan aap YouTube channel link aur Facebook Page ID daalte hain.
2. **Auto-Fetch & Download**: Server automatic YouTube se latest video check karta hai aur format normalize karta hai.
3. **Auto-Post to Facebook**: Direct Facebook Graph API se aapke page par video post kar deta hai.
4. **Duplicate Protection**: Purane upload ho chuke videos ko skip kar deta hai.
5. **24/7 Cloud Server**: Cloud par 24 ghante chalta rehta hai, aapka computer off rehne par bhi auto-posting nahi rukti.

---

## 🚀 Cloud Par 1-Click Free Hosting (Render.com)

Aapka PC band rehne par bhi auto-posting chalane ke liye is Web App ko **Render.com** par 5 minute me free host karein:

1. [GitHub.com](https://github.com) par account banayein aur `c:\Automtion Tools` folder ki files upload karein.
2. [Render.com](https://render.com) par jayein -> **New Web Service** -> Apni Repository select karein.
3. **Deploy** button click kar dein!

Aapka web app internet par live ho jayega aur 24/7 auto-posting karta rahega!
